## 中文

智能手机旅行应用UI设计,9:16竖屏比例,2160x3840分辨率,300 DPI,PNG格式,sRGB色彩空间。展示云南旅程规划界面,融合Google Maps风格与现代移动应用美学。

整体布局:垂直滚动界面,顶部8%区域为状态栏与标题栏,显示"滇·Yunnan Journey"标题和日期"2025.06.15 - 06.22"。主体92%区域为交互式地图与行程信息。底部信息条显示当前位置环境数据。

地图元素:基于Google Maps风格的交互式地图占据中央区域,显示云南西北部地理区域。地图包含3个自定义Pin标记点:① 大理古城(Dali Ancient Town) 25.6948°N, 100.1674°E;② 玉龙雪山(Jade Dragon Snow Mountain) 27.1196°N, 100.2383°E;③ 雨崩村(Yubeng Village) 28.3911°N, 98.8692°E。Pin之间以路径连线,标注距离:1到2为180 km,2到3为220 km,总行程400 km。地图方向标注"N↑"指向正北。

Pin点设计:每个Pin包含编号圆圈、地点名称、GPS坐标和小型人物头像缩略图(占Pin区域25-35%)。头像必须保持清晰面部特征,即使在1/6缩小尺寸下眼睛、鼻子、嘴巴仍清晰可辨,应用面部细节保留算法,轻微锐化面部特征,背景可轻微模糊但面部必须水晶般清晰,300 DPI最低渲染质量。

行程时间线:地图下方15-20%区域显示3个日期标记,对应3个目的地:06.16、06.18、06.20,使用Amatic SC或Shadows Into Light手写风格字体,配合温度图标显示各地天气:-5°C、+3°C、+6°C。

信息卡片:界面中部67%区域为半透明信息卡片,显示当前选中地点详情、照片缩略图网格(85-90%可见度)、导航按钮组。卡片使用rgba(0,0,0,0.45)到rgba(0,0,0,0.35)渐变半透明黑色背景,柔和阴影8-10px模糊半径。

底部状态栏:固定在屏幕底部,深色半透明背景rgba(0,0,0,0.6),显示实时环境数据:温度图标22°C、海拔图标2400m、指南针图标与GPS坐标、总行程"Total Distance: 400 km"。字体大小14-16pt主文本,10-12pt副文本。

配色方案:主色调#F5F5F5(浅灰背景)、#FFFFFF与#F2F2F2(白色元素)、#F9A825(Pin标记黄色)、#AAD3DF(路径线蓝色)、#C8E6C9(区域填充绿色)、#E0E0E0(分隔线灰色)。

交互元素:地图支持双指缩放与拖拽,Pin可点击展开详情,路径显示动画效果,照片缩略图可左右滑动浏览。顶部标题栏Futura Bold字体,数据标签Helvetica Neue字体,装饰性文字Amatic SC手写字体。

细节要求:所有文字边缘清晰无锯齿,图标使用矢量格式确保缩放质量,地图瓦片高分辨率加载,Pin投影效果5-6px柔和阴影,整体界面流畅60fps动画性能。

## English

Smartphone travel app UI design, 9:16 portrait aspect ratio, 2160x3840 resolution, 300 DPI, PNG format, sRGB color space. Showcasing Yunnan journey planning interface, blending Google Maps style with modern mobile app aesthetics.

Overall Layout: Vertically scrollable interface with top 8% area for status bar and header showing "滇·Yunnan Journey" title and dates "2025.06.15 - 06.22". Main 92% area for interactive map and itinerary information. Bottom info bar displaying current location environment data.

Map Elements: Google Maps-style interactive map occupying central area, showing northwestern Yunnan geography. Map contains 3 custom Pin markers: ① Dali Ancient Town at 25.6948°N, 100.1674°E; ② Jade Dragon Snow Mountain at 27.1196°N, 100.2383°E; ③ Yubeng Village at 28.3911°N, 98.8692°E. Pins connected by path lines marked with distances: 1 to 2 is 180 km, 2 to 3 is 220 km, total journey 400 km. Map orientation marked "N↑" pointing true north.

Pin Design: Each Pin includes numbered circle, place name, GPS coordinates, and small profile photo thumbnail (occupying 25-35% of Pin area). Avatars must maintain sharp facial features - eyes, nose, mouth clearly recognizable even at 1/6 reduced size, apply facial detail preservation algorithm, slight sharpening on facial features only, background can be slightly blurred but face must be crystal clear, 300 DPI minimum rendering quality.

Journey Timeline: Below map, 15-20% area displays 3 date markers corresponding to 3 destinations: 06.16, 06.18, 06.20, using Amatic SC or Shadows Into Light handwritten style fonts, paired with temperature icons showing local weather: -5°C, +3°C, +6°C.

Info Cards: Mid-interface 67% area for semi-transparent info cards displaying selected location details, photo thumbnail grid (85-90% visibility), navigation button group. Cards use rgba(0,0,0,0.45) to rgba(0,0,0,0.35) gradient semi-transparent black background, soft shadow 8-10px blur radius.

Bottom Status Bar: Fixed at screen bottom, dark semi-transparent background rgba(0,0,0,0.6), showing real-time environment data: temperature icon 22°C, elevation icon 2400m, compass icon with GPS coordinates, total journey "Total Distance: 400 km". Font sizes 14-16pt main text, 10-12pt secondary text.

Color Scheme: Primary tones #F5F5F5 (light gray background), #FFFFFF and #F2F2F2 (white elements), #F9A825 (Pin marker yellow), #AAD3DF (path line blue), #C8E6C9 (area fill green), #E0E0E0 (divider gray).

Interactive Elements: Map supports pinch-zoom and drag, Pins clickable to expand details, path shows animation effects, photo thumbnails swipeable left-right. Top header Futura Bold font, data labels Helvetica Neue font, decorative text Amatic SC handwritten font.

Detail Requirements: All text edges crisp anti-aliased, icons use vector format ensuring scaling quality, map tiles high-resolution loading, Pin shadow effect 5-6px soft shadow, overall interface smooth 60fps animation performance.
