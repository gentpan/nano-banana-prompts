## 中文

```
为 Nano Banana Pro 做了一些调整。我想为它添加更多相关元素。
提示词：为星月夜这样做<指令>
输入 A 是一幅名画（例如，蒙娜丽莎、呐喊）。分析：笔触技法、隐含的 3D 深度和隐藏符号。
目标：一个"颜料管挤压"。一支巨大、逼真的油画颜料管坐在调色板上。
规则：
动作：管子被挤压，流出的颜料不仅仅是一团，而是形成画作的 3D 景观。蒙娜丽莎的面孔从 2D 颜料涂抹中以 3D 浮雕涌现。
纹理：粘稠、厚重的油画颜料纹理（厚涂）。
道具：画笔、脏抹布、调色刀，加上文化相适应的工具和环境，以及画家的微型 3D 打印版本坐在桌上的小画架上绘画，还有一份报纸头条涵盖其背后的灵感。
照明：北光工作室照明，真实色彩呈现。输出：
一张图像，4:5，"艺术过程"美学。</指令>
```
